The "Heavy Bundle" Problem

Every page currently imports Three.js synchronously. This creates a "monolithic" load experience where the user waits for the entire 3D engine before seeing the first pixel.

Choose Our Strategy

A

Dynamic Route Splitting

Use next/dynamic to lazy-load 3D scenes. Reduces initial JS payload by ~600kb. Instant first-paint for text content.

B

Geometry LoD & Buffer Optimization

Reduce polygon counts for background elements. Switch to BufferGeometry where possible. Higher battery life for mobile users.

C

Asset Pre-warming (R2/KV)

Implement service-worker caching for 3D assets and audio. Zero-latency subsequent visits.

Leverage Points

  • Dynamic imports provide the most "perceived" speed boost.
  • LoD optimization solves the "overheating laptop" syndrome.

Trade-offs

  • Pre-warming adds complexity to the worker logic.
  • Dynamic loading can cause a "pop-in" effect for 3D scenes.
